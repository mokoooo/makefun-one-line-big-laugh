A small Python entry for the "One Line, Big Laugh" bounty. `main.py` (Python 3, standard library only) writes a single line to `/output/entry.txt`, and an AI judge compares entries pairwise on how funny they are. The line: "My therapist charges $200 an hour to tell me my mother was right; my mother does it for free, louder, and with receipts."

## Run it
```sh
python3 main.py
```
